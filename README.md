\# Merc



\*\*Merc\*\* is a lightweight HTTP server framework being built from scratch in modern C++ to understand the internals of web servers, HTTP request processing, routing, and multithreaded networking.



> 🚧 \*\*Project Status:\*\* Under Active Development



\## Features Implemented



\* Basic framework architecture

\* Request and Response abstractions

\* Error handling interface

\* Callback-based routing

\* URL routing infrastructure using `std::map`

\* Response buffering using `std::forward\_list`

\* Content-Type support

\* Validator interface for URL, MIME type, and path validation

\* Static resource folder configuration

\* Sample HTML endpoints



\## Planned Features



\* Socket creation

\* Bind and listen

\* Accept incoming client connections

\* HTTP request parsing

\* Static resource serving

\* GET and POST request handling

\* Multithreaded request processing

\* Thread pool

\* Logging

\* MIME type detection



\## Technologies



\* Modern C++

\* Standard Template Library (STL)

\* Socket Programming \*(in progress)\*

\* Multithreading \*(planned)\*



\## Goal



The objective of this project is to build a lightweight HTTP server framework from scratch while gaining a deeper understanding of:



\* Socket Programming

\* HTTP Protocol

\* Routing

\* Concurrent Programming

\* Web Server Architecture

\* Modern C++ Design
